# Week 07 — JavaScript DOM

A collection of browser-based JavaScript exercises focused on DOM manipulation and interactive web pages.

## Projects

- `cookie clicker/` — an interactive clicker game
- `dom-jsd13/` — DOM practice
- `jsd13-dom-ex/` — DOM exercises
- `pokemon/` — a Pokémon-themed exercise

## View locally

Open the `index.html` file inside a project folder in your browser. These projects use HTML, CSS, and vanilla JavaScript.
